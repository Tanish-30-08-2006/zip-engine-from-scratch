# 🗜️ The Compression Lab
> A journey into the mechanics of data compression, built from the ground up.

## 🚀 Project Overview
This lab is dedicated to understanding and implementing lossless compression algorithms. We start with the philosophical roots of Information Theory and move toward building a fully functional ZIP-style engine.

## 🛠️ Roadmap
- [x] **Step 1.1: Entropy Philosophy** - Analyzing data redundancy and predictability.
- [ ] **Step 1.2: Huffman Coding** - Building the foundation of variable-length encoding.
- [ ] **Step 2.0: Dictionary Methods** - Implementing LZ77/LZ78 logic.
- [ ] **Step 3.0: The Final Engine** - Packaging logic into a `.zip` compatible format.
